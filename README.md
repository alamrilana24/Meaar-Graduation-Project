Meaar is a simple web-based system designed to analyze students’ exam results and evaluate learning performance. It helps faculty members analyze student and course performance through reports.
Features
* Analyze students’ exam results.
* Evaluate student and course performance.
* Analyze exam question performance.
* Measure course learning outcomes.
* Generate reports to help understand results and support decision-making.

Technologies Used
* Python
* Flask
* HTML
* CSS
* JavaScript
* SQLite

To simplify the process of analyzing students’ exam results for faculty members and provide useful information to help evaluate student performance and course learning outcomes.
